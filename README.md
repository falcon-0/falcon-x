# FALCON X

Premium mobile-first storefront concept for an independent game company.

Open `index.html` directly, or serve the folder with any static server. Checkout is explicitly a simulation: it processes no payments and stores no personal data.

## Included

- Cinematic responsive launch page
- Coming-soon release radar and countdown
- Scarcity indicators for finite physical editions
- Top-selling game collection
- Cart drawer with live totals and item removal
- Safe three-step checkout demo
- Newsletter and game notification interactions
- Original generated artwork stored locally in `assets/`
